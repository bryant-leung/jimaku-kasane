# extension

Chrome Manifest V3 extension in TypeScript, built with [WXT](https://wxt.dev). Commands run from the repo root; see the main [README](../README.md).

## Structure

```
src/
  entrypoints/
    content.ts         every frame: finds the main video, draws the overlay, hotkeys ([ ] \ R S H),
                       reports the episode title (top frame), streams the video's audio (auto-sync,
                       Whisper), reads the video's own Japanese text track, runs the prepare-ahead copy
    background.ts      service worker: per-tab state, AniList + Jimaku lookup (one at a time per tab),
                       offsets per file and per show, auto-sync, Whisper live/prepare-ahead/compare,
                       dictionary lookups, saved cards, history, toolbar badge
    offscreen/         offscreen page: Silero VAD (onnxruntime-web), tab-capture sync, auto-sync sessions,
                       speech segmenting for Whisper (drafts + finished lines)
    popup/             switches, status, file picker, offsets, Auto-sync, compare mode, saved/Anki export,
                       history, Settings (key, prepare ahead, line style, underline level)
  lib/
    parse.ts           .srt / .ass → Cue[] (encodings, tags, bad-line reporting)
    episode.ts         page title → show + episode
    autosubs.ts        AniList franchise walk, episode-number candidates, Jimaku file choice
    sync.ts            speech ↔ cue alignment (interval overlap, or cue starts for gapless TV captions)
    vad.ts             Silero VAD wrapper (16 kHz, 512-sample frames)
    overlay.ts         top-layer popover overlay in a shadow root: lines, clickable words, dictionary card,
                       study mode, listening practice, style
    dict.ts            offline JMdict lookup (gzipped buckets), longest-match word splitting, level marking
    deinflect.ts       inflected form → dictionary form rules
    compare.ts         Whisper vs file scoring (CER, timing)
    cards.ts           saved lines/words, Anki export
    history.ts         episode history entries
    badge.ts           toolbar badge for a tab's state
    subs.ts, cue.ts    shared types, messages, storage keys, current/replay line
public/
  vad/                 silero_vad_16k_op15.onnx (MIT), pcm-worklet.js
  dict/                generated by `npm run dict` (gitignored): forms/ and entries/ buckets, meta.json
wxt.config.ts          manifest; copies ONNX Runtime wasm into ort/
```

## Manifest

| Setting | Why |
|---|---|
| `content_scripts`: `<all_urls>`, `all_frames` | players live in cross-origin iframes; site-agnostic |
| `permissions`: `storage` | offsets, settings, per-tab state |
| `permissions`: `tabCapture`, `offscreen` | Auto-sync button (manual) and the offscreen VAD page |
| `host_permissions`: jimaku.cc, graphql.anilist.co, 127.0.0.1 | subtitle lookup; local Whisper server |
| CSP `wasm-unsafe-eval` (extension pages) | runs the bundled ONNX Runtime; no remote code |

## Storage

| Key | Area | Holds |
|---|---|---|
| `tab:<tabId>` | session | loaded cues for a tab |
| `auto:<tabId>`, `sync:<tabId>` | session | lookup / sync status shown in the popup |
| `offset:<fileKey>` | local | offset for one subtitle file |
| `showOffset:anilist:<id>` | local | last offset for a show (inherited by its next episode) |
| `synced:<fileKey>` | local | auto-sync done for this file |
| `show:<title>` | local | AniList franchise cache (12 h) |
| `jimakuKey` | local | Jimaku API key |
| `prepTabs` | session | prepare-ahead copy tab → your tab |
| `compare:<tabId>` / `compareReports` | session / local | running comparison / scores per file |
| `pagetrack:<tabId>` | session | the page has its own Japanese track |
| `syncBias` | local | your usual correction to auto-sync |
| `enabled`, `disabledSites` | local | on/off switches |
| `prepareAhead`, `markAbove`, `studyMode`, `listenMode`, `subStyle` | local | settings |
| `savedCards` | local | lines/words saved for review |
| `history` | local | last 30 episodes |
